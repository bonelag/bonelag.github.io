# Personal GitHub Page

Trang cá nhân tĩnh được tối ưu để chạy trên GitHub Pages.

## Chỉnh nhanh thông tin cá nhân

Mở `index.html` và thay các phần sau:
- `BoneLag`
- Link GitHub trong các thẻ `href="https://github.com"`
- Email trong `href="mailto:you@example.com"`
- Nội dung phần dự án và kỹ năng

## Chạy local

Chỉ cần mở `index.html` trong trình duyệt.

## Deploy GitHub Pages

1. Push toàn bộ code lên repo `username.github.io` (hoặc repo thường).
2. Vào **Settings → Pages**.
3. Chọn source là branch `main` (root `/`).
4. Save, chờ vài phút để site lên.

URL sẽ có dạng:
- `https://username.github.io` (nếu repo là `username.github.io`)
- `https://username.github.io/repo-name` (nếu repo thường)
